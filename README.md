# CCCA5-Refugia

Repository hosting R code for reproducing figures from "IDENTIFYING
CLIMATE CHANGE REFUGIA IN COASTAL AND PELAGIC OCEAN HABITATS": a report
for California’s Fifth Climate Change Assessment
(CNRA-CCC5-2026-5CAP46).

**Authors:**

-   Mikaela M. Provost, UC Davis
-   Jessica Bolin, UC Davis
-   Mercedes Pozo Buil, UC Santa Cruz
-   Nerea Lezama-Ochoa, UC Santa Cruz
-   Barbara Muhling, UC Santa Cruz
-   Steven Bograd, NOAA
-   Allison Dedrick, CDFW
-   Abby Mohan, OPC

Note that we have not provided code for reproducing figures that use
confidential fisheries data.
